## Dataset 1: De Bari et al. (2024)

**Source.** D. De Bari, G. Garaccione, R. Coppola, M. Torchiano, L. Ardito. *Evaluating Large Language Models in Exercises of UML Class Diagram Modeling.*
ESEM '24, pp. 393–399, 2024.
Original dataset: http://doi.org/10.6084/m9.figshare.25434550

**Content.** 20 UML class-diagram modelling exercises, each consisting of a natural-language description and a reference class diagram. The exercises were
originally collected by De Bari et al. from educational sources on the web.

**Use in this study.** Each description was submitted to DeepSeek-R1 at three temperature settings (0, 0.6, 1.0), yielding 60 runs used for manual taxonomy
construction (RQ1), distribution analysis (RQ2), and correlation analysis (RQ3). 
The same 20 descriptions were also submitted to DeepSeek-V4-Pro for the cross-model analysis.
